PLAINTEXT DB PASSWORD IN CONNECTOR CONFIG — found 2026-08-20T08:45Z.  NOT FIXED.

WHAT THE TEMPLATE CLAIMS
  connectors/oracle/corebank-source.json.tmpl, "_comment_credentials":
    "CLAUDE.md 3.1 - no plaintext password. The SSM config provider resolves these at
     task start; the literal never exists in the connector config, in Kafka, or in the
     REST response."

WHAT ACTUALLY HAPPENS
  docker/cdc-runtime/connect-worker.properties:102-104 -- the provider is COMMENTED OUT:
    #config.providers=ssm
    #config.providers.ssm.class=com.github.jcustenborder.kafka.config.aws.SsmParamStoreConfigProvider
    #config.providers.ssm.param.aws.region=${AWS_REGION}

  So scripts/register-connectors.sh resolve() substitutes the SECRET ITSELF into the JSON
  before POSTing it. `register-connectors.sh render` prints the live password to the
  terminal, and the registered connector carries it:

    - in Connect's REST API and in GET /connectors/<name>/config
    - in the connect-configs Kafka topic, replicated, at rest
    - in any operator's scrollback

  That is the opposite of the comment, and it violates CLAUDE.md 3.1.

WHY IT WAS NOT FIXED IN THIS SESSION
  Enabling the provider needs kafka-config-provider-aws on the Connect classpath. That jar
  is NOT in versions.env or /opt/connect-plugins -- the same missing-artifact class of
  defect as the Apicurio converter (OPEN-14). Adding it mid-validation would restart
  Connect again; the validation run needs the connector up.

  Accepted for THIS lab window, deliberately and with the reasons stated:
    - the password is a generated lab secret in SSM, not a shared or human credential
    - Oracle listens on a private IP, reachable only from inside the VPC
    - the whole stack is destroyed at the end of the window

  1. Stage kafka-config-provider-aws in versions.env (with a real SHA256) and mount it
     into /opt/connect-plugins/libs like the MSK IAM jar.
  2. Uncomment config.providers in connect-worker.properties.
  3. Delete resolve()'s ${ssm:...} substitution so the placeholder survives into the POST.
  4. ROTATE /kafka-dev-lab/dev/source-lab/oracle-cdc-password and
