-------------------------------------------------------------------------------

  cost: 1.00 USD/month (docs/PRICE_REFERENCE.md section 6) - always-on, by design

  [dry-run] aws kms enable-key-rotation --key-id <id>

Verification (ADR-021)
-------------------------------------------------------------------------------
  After executing, confirm all four:

    aws s3api get-bucket-versioning --bucket aws-cdc-lakehouse-tfstate-111122223333 \
      --profile my-aws-profile --region ap-southeast-1          # Status: Enabled

    aws s3api get-public-access-block --bucket aws-cdc-lakehouse-tfstate-111122223333 \
      --profile my-aws-profile --region ap-southeast-1          # all four true

    aws s3api get-bucket-encryption --bucket aws-cdc-lakehouse-tfstate-111122223333 \
      --profile my-aws-profile --region ap-southeast-1          # aws:kms

    curl -s -o /dev/null -w '%{http_code}\n' \
      http://aws-cdc-lakehouse-tfstate-111122223333.s3.ap-southeast-1.amazonaws.com/      # 403, not 200

  Then, after the first Stage B apply, the rule that matters most:

    terraform -chdir=terraform/envs/dev state list | grep -c "aws-cdc-lakehouse-tfstate-111122223333"   # 0

  A non-zero count means the stack manages its own state bucket. That is the failure
  ADR-021 exists to prevent, and it must be fixed before any destroy.
