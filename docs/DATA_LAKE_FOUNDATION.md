## 3. S3 layout

Normative source: `docs/DATA_CONTRACTS.md` §8. Implemented as `lake_prefixes`.

```
s3://<lake>/warehouse/{stream,full_cdc,snapshot,curated,mart,ops,quarantine}/
s3://<lake>/checkpoints/          <-- TOP-LEVEL SIBLING, not under warehouse/
s3://<lake>/dq-results/
s3://<lake>/quarantine-payloads/
s3://<lake>/query-results/athena/
s3://<lake>/logs/{airflow,emr-serverless}/
```

**`checkpoints/` is a top-level sibling and a variable validation enforces it.** Iceberg's
`remove_orphan_files` walks a table's location and deletes unreferenced files. A
checkpoint under `warehouse/` is exactly that — unreferenced — so maintenance would
silently destroy streaming state. `CLAUDE.md` §5.9 exists for this failure; the
validation makes it unrepeatable.

`warehouse/ops/` closes defect **D7**: `ops.reconciliation_run` was specified in
`reference/RECONCILIATION_AND_ACCURACY.md` but had no prefix and no database.

### Lifecycle rules

| Prefix | Rule | Why |
|---|---|---|
| `query-results/` | expire 7 d | Derived; regenerated by re-running the query |
| `checkpoints/` | noncurrent versions expire 14 d | **Must exceed the longest replay window.** Kafka retention is 24 h; a validation rejects < 2 days |
| `logs/` | expire 3 d | ADR-030 floor cut |
| `dq-results/`, `quarantine-payloads/` | expire 30 d | Defect evidence outlives logs |
| *(all)* | abort incomplete multipart after 7 d | A failed Spark write leaves parts that bill as storage and are invisible in the object list |
| `warehouse/` | **no expiration rule, deliberately** | Iceberg manages its own snapshot expiry. An S3 rule here would delete live data files out from under table metadata |

Four properties worth stating explicitly:

- **`spark_eod` has no Kafka access at all.** L3, marts and Iceberg maintenance read L1/L2
  from S3. This is what makes six sessions runnable with no cluster — the $2.53 lake-only
  window in `docs/SESSION_DEPENDENCY_GRAPH.md` §5.
- **`airflow` is read-only on the lake.** `CLAUDE.md` §7: DAGs orchestrate, they do not
  transform. Write access would make it possible to violate that by accident.
- **`athena_bi` cannot write.** `CLAUDE.md` §8: Power BI reads marts, never L1/L2.
- **Reading a secret needs two grants.** `ssm:GetParameter` **and** `kms:Decrypt` on the
  platform key, `kms:ViaService`-scoped to SSM. A role with one and not the other fails
  closed — Session 04 must test that, because a secret store that returns nothing
  silently is worse than one that errors.

Full derivation: `artifacts/validation/session-02/stage-b/cost-estimate.txt`.

| | |

The floor is *lower* than `docs/COST.md`'s $2.28 because this stack creates no Secrets
Manager secret (ADR-031), holds no lake data yet, and excludes the out-of-band state
bucket. The 6 CloudWatch alarms sit inside `kafka_platform`'s lifecycle, so they cost

**At $0.8052/hr the entire monthly budget is gone in 37 hours.** Destroy at the end of
every window; do not stop (ADR-027).

## 9. Rollback

Nothing has been applied, so rollback today is `git checkout`. After an apply:

```bash
cd terraform/envs/dev
terraform plan -destroy -var-file=terraform.tfvars      # review first
terraform destroy -var-file=terraform.tfvars

# then VERIFY — a destroy that reports success is not evidence
aws kafka list-clusters-v2 --profile my-aws-profile --region ap-southeast-1 --query 'length(ClusterInfoList)'
aws ec2 describe-instances --profile my-aws-profile --region ap-southeast-1 \
  --query 'Reservations[].Instances[?State.Name!=`terminated`].InstanceId'
aws ec2 describe-volumes --profile my-aws-profile --region ap-southeast-1 --query 'Volumes[].VolumeId'
aws ec2 describe-vpc-endpoints --profile my-aws-profile --region ap-southeast-1 --query 'VpcEndpoints[].VpcEndpointId'
```

**`terraform destroy` will fail on a non-empty lake bucket** while
`allow_destroy_with_data = false`. That is the session's acceptance criterion working:
destroying compute must never silently delete lake data. To drop the lake deliberately,
set the flag to `true` and re-plan — an explicit act, recorded in the diff.

The two KMS CMKs enter a 7-day deletion window rather than disappearing, and **continue
to bill $1/month each until it elapses**. A destroy verified the same day will still show
$2.00 of floor.
